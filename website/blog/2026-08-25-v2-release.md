cc-discord-framework v2.0.0 を npm に公開しました。今日から
`bun add @cc-discord-framework/core` で導入できます。

{/* truncate */}

## パッケージ構成

v2 からは、すべてのパッケージを npm の
[`@cc-discord-framework`](https://www.npmjs.com/org/cc-discord-framework)
スコープに集約します。

| パッケージ | バージョン | 内容 |
| --- | --- | --- |
| [`@cc-discord-framework/core`](https://www.npmjs.com/package/@cc-discord-framework/core) | 2.0.0 | フレームワーク本体(discord.js 14 を同梱・再エクスポート) |
| [`@cc-discord-framework/utils`](https://www.npmjs.com/package/@cc-discord-framework/utils) | 1.0.0 | 定期実行・確認 UI・ページ送り・整形などの詰め合わせ |
| [`@cc-discord-framework/music`](https://www.npmjs.com/package/@cc-discord-framework/music) | 1.0.0 | 音楽再生エンジン(キュー・再生制御・差し替え可能な音源機構) |
| [`@cc-discord-framework/music-sources`](https://www.npmjs.com/package/@cc-discord-framework/music-sources) | 1.0.0 | YouTube / SoundCloud を music の音源として追加 |
| [`@cc-discord-framework/ai`](https://www.npmjs.com/package/@cc-discord-framework/ai) | 1.0.0 | 複数プロバイダー対応の AI 機能と `AiTool` |

## はじめかた

```sh
bun add @cc-discord-framework/core
```

これだけで discord.js も一緒に入ります。最初の Bot までの手順は
[インストールガイド](/docs/framework/getting-started/installation/)へ、
プラグインの導入は[公式プラグイン](/docs/plugins/)へどうぞ。

## 旧パッケージ(v1)について

npm のスコープなしパッケージ `cc-discord-framework`(latest = 1.0.5)は
旧世代の v1 で、v2 とは API 互換ではありません。今後の開発はすべて
`@cc-discord-framework` スコープで行います。新規導入では必ず
`@cc-discord-framework/core` を使ってください。詳しくは
[プロジェクト状況](/docs/framework/project-status/)にまとめています。
